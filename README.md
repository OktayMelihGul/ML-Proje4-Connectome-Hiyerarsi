# Project 4: Unreachable neurons in the connectome hierarchy

**Question:** in the *Drosophila* connectome, does the common practice of dropping neurons that cannot be reached
from the sensory set bias depth and hierarchy results, and by how much?

**Approach:** shortest-path depth from sensory neurons in FlyWire FAFB v783 and Janelia MaleCNS v1.0; a Poisson
regression, written from scratch in NumPy, that treats unreachable neurons as right-censored observations; and a
comparison of coefficients across three models (dropped OLS, dropped Poisson, censored Poisson).

## Conventions and decisions applied

Source columns → schema (full print of the pinned files in `reports/source_columns.txt`):

| Target | FAFB (783 + annotations v3.2.0) | MaleCNS (neuPrint v1.0) |
|---|---|---|
| neuron_id | `proofread_root_ids_783.npy` | `bodyId` |
| cell_type / cell_class / cell_sub_class | `cell_type` / `cell_class` / `cell_sub_class` | `type` / `class` / `subclass` |
| super_class | `super_class`; `sensory_ascending` → sensory | `superclass`, mapped (below) |
| side | `side` (`na` → unknown) | `somaSide`, else `rootSide` (L/R/M → left/right/center) |
| region | neuropil with most connections in edgeroi (inputs + outputs); `UNASGD` kept | primary ROI with the largest roiInfo `upstream + downstream`; ROI name verbatim |
| nt_type / nt_confidence | `top_nt` / `top_nt_conf` | `predictedNt` (`unclear` → unknown) / `predictedNtConfidence` (blanked where nt_type is unknown) |
| n_pre / n_post | missing (not provided) | `pre` / `post` |
| pre_id, post_id, syn_count, neuropil | `pre_pt_root_id`, `post_pt_root_id`, `syn_count`, `neuropil` | `body_pre`, `body_post`, count of partner rows, `primary_post` |

MaleCNS superclass mapping: ol_intrinsic → optic; cb_intrinsic → central; visual_projection(_tbc) → visual_projection;
visual_centrifugal → visual_centrifugal; cb/ol/vnc_sensory(_tbc), sensory_descending, sensory_ascending(_tbc) → sensory;
ascending_neuron → ascending; descending_neuron → descending; cb/vnc_motor → motor; cb/vnc_endocrine → endocrine;
everything else → unknown (config.py has no MaleCNS-only levels yet). Cross-dataset neuropil names come from eda_shared
(`canonical_neuropil`).

- **Region measure:** MaleCNS region = primary ROI with the largest roiInfo upstream + downstream (connection counts,
  the same unit as FAFB's edgeroi count).
- **Unspecified regions:** Optic-unspecified(L/R) and CentralBrain-unspecified keep their label (365 + 359 + 37 = 761
  neurons). `src/provisional.py` passes two extra rows to `add_provisional_flags(table=...)` (Optic-unspecified: is_optic
  True; CentralBrain-unspecified: is_optic False; both region_group unknown); eda_shared itself is unchanged.
- **FAFB UNASGD (9) and no-edge neurons (616):** kept, region_group unknown, is_optic False; FAFB is never filtered by in_brain.
- **Tie rule (default):** alphabetical by neuropil name (ties: FAFB 319, MaleCNS 81).
- **Nerve cord (default):** the 60 primary ROIs under the `VNC` branch of the neuPrint male-cns:v1.0 ROI hierarchy,
  including VNC-unspecified (`reports/malecns_nerve_cord_rois.txt`); the MaleCNS brain set is in_brain (142,757 neurons).
- **Other defaults:** FAFB `sensory_ascending` (612) → sensory, so they are seeds; MaleCNS-only superclasses → unknown.
- **Self-connections dropped:** FAFB 0; MaleCNS 101 pairs (473 synapses) in edges, 131 rows in edgeroi.
- **FAFB neuron ids:** 139,255 neurons (the proofread list). 14 proofread ids without an annotation row appear in edges
  and are kept with unknown labels; 7 annotation-only ids (not proofread, no edges) are dropped.
